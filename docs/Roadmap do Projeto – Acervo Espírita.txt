🥈 FASE 2 — Modelagem (ESSENCIAL) ← AGORA

- Modelagem do banco com entidade única `User`
- Controle de permissões via `Role`
- Remoção da entidade `Staff`
- Definição de relacionamentos principais

⚠️ Essa é a fase mais importante

📌 2.1 Modelar o banco de dados

Você precisa definir tabelas como:

users
books
loans
staff
locations (estante/prateleira)
logs

👉 Resultado:

/database/schema.sql
📌 2.2 Modelar entidades (Java)

Criar classes:

User
Book
Loan
Employee
Location
Log

👉 Isso evita bagunça depois

📌 2.3 Relacionamentos (muito importante)

Definir:

Um usuário → vários empréstimos
Um livro → um empréstimo por vez
Livro → localização
